# Smart Expense Tracker

## Overview
Smart Expense Tracker is a full-stack web application developed using Java, MySQL, HTML, CSS, and JavaScript. The application helps users manage daily expenses, track spending categories, and analyze financial records efficiently.

## Features
- User authentication and login
- Expense management
- Category tracking
- Financial reports
- Responsive user interface
- MySQL database integration

## Technologies Used
- Java
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure
- Frontend
- Backend
- Database
